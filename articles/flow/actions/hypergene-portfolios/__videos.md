#### Integrating Hypergene Portfolios and Microsoft Fabric using Flow
This video shows a simple demo of how to get started integrating Hypergene Portfolios and Microsoft Fabric to display data from Portfolios in Power BI reports.  
The demo fetches data from the Portfolios API and imports it to a Fabric SQL database that a Power BI model is connected to.
