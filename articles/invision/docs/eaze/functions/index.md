# Function Reference

All Eaze built-in functions organized by family. Function names follow Excel convention — UPPERCASE for the spreadsheet library, mixed-case for system/styling/row helpers.

| Family | Functions |
|---|---|
| [Logical](logical.md) | `TRUE`, `FALSE`, `NOT`, `IF`, `COALESCE` / `FIRSTNOTNULL`, `ISNULL`, `ISNULLORZERO`, `ISNULLOREMPTYSTR`, `ISNUMBER`, `ISNUMERIC`, `ISERROR`, `IFERROR`, `NZ` |
| [Math / Trig](math.md) | `ABS`, `SIGN`, `ROUND`, `CEILING`, `FLOOR`, `SUM`, `MOD`, `POW`, `EXP`, `LN`, `LOG`, `LOG10`, `SIN`, `COS`, `TAN`, `ASIN`, `ACOS`, `ATAN`, `ATAN2`, `SQRT`, `PI`, `RAND`, `NUM_MIN` |
| [Statistical](statistical.md) | `AVERAGE` / `AVERAGEA`, `COUNT` / `COUNTA` / `COUNTBLANK`, `MAX` / `MAXA`, `MIN` / `MINA`, `STDEV` / `STDEVA` / `STDEVP` / `STDEVPA`, `VAR` / `VARA` / `VARP` / `VARPA` |
| [Text](text.md) | `CONCAT`, `SUBSTRING`, `SPLIT`, `LEFT`, `RIGHT`, `LEN`, `REPLACE`, `LOWER`, `UPPER`, `TRIM`, `TOSTRING`, `TONUMBER`, `NEWLINE` |
| [Date](date.md) | `DATE`, `DATEVALUE`, `TODATE`, `NOW`, `FORMATDATE`, `TZUTC`, `TZLocal` |
| [Time Frame helpers](timeframe-dates.md) | `DateStart`, `DateEnd`, `YearNum`, `MonthNum`, `WeekNum`, `DayOfWeekName`, `DayOfMonthNum`, … |
| [Financial](financial.md) | `AMORLINC`, `AMORLINCMTH` |
| [System](system.md) | `ARRAY`, `NEWID`, `Window`, `EVAL`, `JsonParse`, `JsonStringify`, `ApiBase` |
| [Misc / LHS helpers](misc.md) | `LHS`, `LHSVALUE`, `tmpl_foreach_operand` |
| [Row Collection](row-collection.md) | `ADDROWFIRST`, `ADDROWLAST`, `ADDROWAFTER`, `ADDROWBEFORE`, `IsSummaryRow`, `IsRowLocked`, `GetCallContextRow` |
| [Cell and Row Styling](styling.md) | `SETROWSTYLE`, `SETCELLSTYLE` |
