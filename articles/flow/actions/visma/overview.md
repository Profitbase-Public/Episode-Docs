# Visma overview

Flow includes built-in support for two products from the [Visma](https://www.visma.com/) family — [Visma Business NXT](./visma-business-nxt/overview.md) and [Visma.Net](./visma-net/overview.md). The two products are integrated through different APIs, so each has its own connection and its own set of actions. Pick the subcategory that matches the Visma product you're integrating with.

<br/>

## Explore

#### [Visma Business NXT](./visma-business-nxt/overview.md)
Integrates with [Visma Business NXT](https://docs.vismasoftware.no/businessnxtapi/) through its GraphQL API. The dedicated **Get Visma Business NXT data** action runs a GraphQL query against the API and returns the result as a streaming DataReader, ready to be piped into a database or other downstream actions.

<br/>

#### [Visma.Net](./visma-net/overview.md)
Integrates with [Visma.Net](https://integration.visma.net/API-index/) through its REST API. Provides generic REST API Request actions (with and without paging) for calling any Visma.Net endpoint — for retrieving customers, projects, invoices, and accounting records, or for creating and updating records.
